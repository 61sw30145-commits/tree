ซิงค์ข้ามอุปกรณ์และจัดการข้อมูลย้อนหลัง

เชื่อมต่อกับ Google Sheet เพื่อซิงค์ข้อมูลฟรีระหว่างมือถือและคอมพิวเตอร์ผ่าน GitHub Pages

วิธีเปิดใช้งาน Google Sheets Sync & GitHub Pages

1. ขั้นตอนสร้างระบบซิงค์ (Google Sheets):

  1. สร้าง Google Sheet ใหม่ใน Google Drive
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมออก วางโค้ด Google Apps Script สั้นๆ สำหรับรับ/ส่งข้อมูล JSON
  4. กด นำออกใช้งาน (Deploy) > การนำออกใช้งานใหม่ (New Deployment)
  5. เลือกประเภทเป็น เว็บแอป (Web app) และตั้งค่า ผู้ที่มีสิทธิ์เข้าถึง (Who has access) เป็น "ทุกคน (Anyone)"
  6. คัดลอก Web App URL นำมาวางในช่องด้านบนแล้วกดบันทึก

2. ขั้นตอนลงเว็บด้วย GitHub Pages:

  1. อัปโหลดไฟล์ index.html นี้ขึ้น Repository บน GitHub
  2. ไปที่ Settings > Pages เลือก Branch เป็น main แล้วกด Save
  3. เปิดใช้งานผ่าน URL ของ GitHub Pages ได้ทันทีทุกอุปกรณ์!
